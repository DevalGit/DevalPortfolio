# Deval Mevada — Full Stack Developer & Cybersecurity Enthusiast

A modern, premium portfolio built with **React**, **Vite**, and **Tailwind CSS**.

Designed around a clean **Developer Operating System** aesthetic with a dark navy and cyan visual identity, showcasing my development experience, projects, technical skills, and journey into cybersecurity.

## Features

* **High-Performance SPA**: Built with Vite for fast development, HMR, and optimized production builds.
* **Custom Design System**: Uses a structured CSS token system for consistent styling and theming.
* **Fully Responsive**: Designed for a smooth experience across desktop, tablet, and mobile devices.
* **Project Showcase**: Highlights selected full-stack, frontend, and real-world development projects.
* **Developer Journey**: Presents key education, experience, and technical milestones.
* **SEO Optimized**: Includes meta tags, Open Graph metadata, and structured data for better discoverability.
* **Production Ready**: Optimized for deployment on platforms such as Netlify and Vercel.

## Tech Stack

* **React.js**
* **Vite**
* **Tailwind CSS**
* **JavaScript**
* **HTML5 / CSS3**

## Local Development

```bash
# Clone the repository
git clone https://github.com/DevalGit/DevalPortfolio.git

# Navigate to the project
cd DevalPortfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## Production Build

```bash
# Build the project for production
npm run build

# Preview the production build
npm run preview
```
